Edge Detection Operators PG5.m

Program 5 • Sobel, Prewitt, Roberts, and Canny Edge Detectors

🎯 Aim

To implement and compare different image edge detection techniques including Sobel, Prewitt, Roberts, and Canny operators using MATLAB.

📋 Procedure
  1. Read the input image ('LENA.JFIF') using imread().
  2. Check if the image is in RGB format; if so, convert it to grayscale using rgb2gray().
  3. Apply edge detection operators using MATLAB's built-in edge() function for Sobel, Prewitt, Roberts, and Canny.
  4. Plot and display the original image and all four edge-detected images using subplot() and imshow().
💻 MATLAB Program (PG5.m)
M PG5.m 
clc;
clear;
close all;

% Read Image
img = imread('LENA.JFIF');

% Convert to Gray
if size(img,3)==3
    img = rgb2gray(img);
end

% Edge Detection
sobel = edge(img,'sobel');
prewitt = edge(img,'prewitt');
roberts = edge(img,'roberts');
canny = edge(img,'canny');

% Display
figure;
subplot(2,3,1), imshow(img), title('Original');
subplot(2,3,2), imshow(sobel), title('Sobel');
subplot(2,3,3), imshow(prewitt), title('Prewitt');
subplot(2,3,4), imshow(roberts), title('Roberts');
subplot(2,3,5), imshow(canny), title('Canny');
✓

Result

Thus, edge detection using Sobel, Prewitt, Roberts, and Canny operators was successfully implemented and the edges were displayed.

Image Compression & Ratio PG6.m

Program 6 • JPEG Quality Factor Adjustment & Compression Ratio Calculation

🎯 Aim

To perform JPEG image compression by specifying the quality factor in MATLAB and calculate the resulting compression ratio.

📋 Procedure
  1. Read the source image ('LENA.JFIF') and convert to grayscale if RGB.
  2. Write the image to a file ('compressed.jpg') with reduced quality (Quality = 30) using imwrite().
  3. Read the compressed JPEG image back using imread().
  4. Display both original and compressed images side-by-side using subplot().
  5. Query file attributes using dir() to extract file sizes in bytes and compute the compression ratio: ratio = original.bytes / compressed.bytes.
💻 MATLAB Program (PG6.m)
M PG6.m 
clc;
clear;
close all;

% Read Image
img = imread('LENA.JFIF');

% Convert to Gray
if size(img,3)==3
    img = rgb2gray(img);
end

% Compress and Save
imwrite(img,'compressed.jpg','Quality',30);

% Read Compressed Image
comp = imread('compressed.jpg');

% Display
figure;
subplot(1,2,1), imshow(img), title('Original');
subplot(1,2,2), imshow(comp), title('Compressed');

% Compression Ratio
o = dir('lena.png');
c = dir('compressed.jpg');
ratio = o.bytes / c.bytes;

fprintf('Compression Ratio = %.2f\n', ratio);

Image Subtraction PG7.m

Program 7 • Image Arithmetic & Absolute Difference (imabsdiff)

🎯 Aim

To perform image subtraction using imabsdiff() between two images to detect differences and changes in MATLAB.

📋 Procedure
  1. Read two input images ('LENA.JFIF' and 'image.JFIF').
  2. Convert both images to grayscale using rgb2gray() if they contain 3 color channels.
  3. Resize the second image to exactly match the dimensions of the first image using imresize().
  4. Calculate the absolute difference between both images using imabsdiff(img1, img2).
  5. Display Image 1, Image 2, and the resulting Subtracted Image using subplot().
💻 MATLAB Program (PG7.m)
M PG7.m 
clc;
clear;
close all;

% Read Images
img1 = imread('LENA.JFIF');
img2 = imread('image.JFIF');

% Convert to Gray
if size(img1,3)==3
    img1 = rgb2gray(img1);
end

if size(img2,3)==3
    img2 = rgb2gray(img2);
end

% Resize Images
img2 = imresize(img2, size(img1));

% Image Subtraction
result = imabsdiff(img1, img2);

% Display
figure;
subplot(1,3,1), imshow(img1), title('Image 1');
subplot(1,3,2), imshow(img2), title('Image 2');
subplot(1,3,3), imshow(result), title('Subtracted Image');
✓

Result

Thus, image subtraction using imabsdiff was successfully performed and the subtracted image was displayed.

Boundary Extraction PG8.m

Program 8 • Morphological Operations (imerode & Subtraction)

🎯 Aim

To extract morphological boundaries of an image using erosion and set subtraction in MATLAB.

📋 Procedure
  1. Read the input image ('LENA.JFIF') and convert it to grayscale.
  2. Binarize the grayscale image using imbinarize() to obtain binary image bw.
  3. Create a flat disk structuring element of radius 1 using strel('disk', 1).
  4. Perform morphological erosion on the binary image using imerode(bw, se).
  5. Compute the morphological boundary by subtracting the eroded image from the binary image: boundary = bw - eroded.
  6. Display the Original, Binary, and Boundary images in a 1x3 subplot grid.
💻 MATLAB Program (PG8.m)
M PG8.m 
clc;
clear;
close all;

% Read Image
img = imread('LENA.JFIF');

% Convert to Gray
if size(img,3)==3
    img = rgb2gray(img);
end

% Convert to Binary
bw = imbinarize(img);

% Morphological Boundary Extraction
se = strel('disk',1);
eroded = imerode(bw,se);
boundary = bw - eroded;

% Display
figure;
subplot(1,3,1), imshow(img), title('Original');
subplot(1,3,2), imshow(bw), title('Binary');
subplot(1,3,3), imshow(boundary), title('Boundary');
✓

Result

Thus, morphological boundary extraction was successfully performed using erosion and subtraction, and the boundary image was displayed.
