Program 01

Image Enhancement

🎯

Aim

To implement image enhancement techniques such as smoothing, sharpening, contrast stretching, gamma correction and sigmoidal enhancement using MATLAB.
📋

Procedure

  • Read the input image.
  • Apply smoothing and sharpening.
  • Perform contrast stretching, gamma correction and sigmoidal enhancement.
  • Display and compare all enhanced images.
💻

MATLAB Program

matlab 
clc;
clear;
close all;

img = imread('lena.png');

figure;

% 1.1 Smoothing
smooth = imfilter(img,fspecial('average',[3 3]));

% 1.2 Sharpening
sharp = imsharpen(img);

% 1.3.1 Contrast Stretching
contrast = imadjust(img,stretchlim(img),[]);

% 1.3.2 Gamma Correction
gamma = im2double(img).^0.7;

% 1.3.3 Sigmoidal Function
x = im2double(img);
sigmoid = 1./(1+exp(5*(0.5-x)));

subplot(2,3,1), imshow(img), title('Original');
subplot(2,3,2), imshow(smooth), title('Smoothing');
subplot(2,3,3), imshow(sharp), title('Sharpening');
subplot(2,3,4), imshow(contrast), title('Contrast');
subplot(2,3,5), imshow(gamma), title('Gamma');
subplot(2,3,6), imshow(sigmoid), title('Sigmoid');
✓

Result

Thus, the image enhancement techniques were successfully implemented and the enhanced images were displayed.

Program 02

Histogram Processing

🎯

Aim

To implement histogram, histogram equalization and histogram specification techniques using MATLAB.
📋

Procedure

  • Read the input and reference images.
  • Find and display the histogram.
  • Perform histogram equalization.
  • Perform histogram specification/matching.
  • Display the results.
💻

MATLAB Program

matlab 
clc;
clear;
close all;

img = imread('lena.png');
ref = imread('penquin.jpg');

% Convert to grayscale
if size(img,3)==3
    img = rgb2gray(img);
end
if size(ref,3)==3
    ref = rgb2gray(ref);
end

% 2.1 Histogram
h = imhist(img);

% 2.2 Histogram Equalization
equal = histeq(img);

% 2.3 Histogram Specification
match = imhistmatch(img,ref);

figure;

subplot(2,3,1), imshow(img), title('Original');
subplot(2,3,2), imhist(img), title('Histogram');
subplot(2,3,3), imshow(equal), title('Equalized');
subplot(2,3,4), imhist(equal), title('Equalized Histogram');
subplot(2,3,5), imshow(match), title('Matched');
subplot(2,3,6), imhist(match), title('Matched Histogram');
✓

Result

Thus, histogram, histogram equalization and histogram specification were successfully implemented and the results were displayed.

Program 03

Image Restoration

🎯

Aim

To restore a degraded and noisy image using Wiener filtering in MATLAB.
📋

Procedure

  • Read the input image.
  • Create a motion blur PSF.
  • Add Gaussian noise to the degraded image.
  • Calculate the noise-to-signal ratio.
  • Apply Wiener filtering.
  • Display the original, degraded and restored images.
💻

MATLAB Program

matlab 
clc;
clear;
close all;

% Read image
img = im2double(imread('penquin.jpg'));

% Motion blur
psf = fspecial('motion',20,45);
blur = imfilter(img,psf,'conv','circular');

% Add Gaussian noise
noise = imnoise(blur,'gaussian',0,0.001);

% Wiener restoration
nsr = 0.001/var(img(:));
restored = deconvwnr(noise,psf,nsr);

% Display
subplot(1,3,1), imshow(img), title('Original');
subplot(1,3,2), imshow(noise), title('Degraded + Noise');
subplot(1,3,3), imshow(restored), title('Restored');
✓

Result

Thus, the degraded and noisy image was successfully restored using the Wiener filter.

Program 04

Image Filtering

🎯

Aim

To implement different image filtering techniques such as Low-pass, High-pass, Median, Sharpening and Gaussian filtering using MATLAB.
📋

Procedure

  • Read the input RGB image.
  • Apply Low-pass and High-pass filters.
  • Apply Median and Sharpening filters.
  • Apply Gaussian filtering.
  • Display and compare all filtered images.
💻

MATLAB Program

matlab 
clc;
clear;
close all;

% Read RGB image
img = imread('lena.png');

% Low-pass
low = imfilter(img,fspecial('average',[3 3]));

% High-pass
high = imfilter(img,fspecial('sobel'));

% Median filter
med(:,:,1) = medfilt2(img(:,:,1));
med(:,:,2) = medfilt2(img(:,:,2));
med(:,:,3) = medfilt2(img(:,:,3));

% Sharpen
sharp = imsharpen(img);

% Gaussian
gauss = imgaussfilt(img,2);

% Display
subplot(2,3,1), imshow(img), title('Original');
subplot(2,3,2), imshow(low), title('Low-pass');
subplot(2,3,3), imshow(high,[]), title('High-pass');
subplot(2,3,4), imshow(med), title('Median');
subplot(2,3,5), imshow(sharp), title('Sharpen');
subplot(2,3,6), imshow(gauss), title('Gaussian');
✓

Result

Thus, the different image filtering techniques were successfully implemented and the filtered images were displayed.
